2Load and convert the certificate

Drop everything the CA or the customer sent — any mix of PEM, DER, PKCS#7 (.p7b), PFX/P12, Java keystore (.jks), or key files in any format. Morpheus Certificate Install reads them by content, puts the chain in order and converts it to what Morpheus needs. This step works without connecting, so you can just convert and download.

4Verify

Checks what nginx serves on the appliance, and the chain and hostname from this machine. Runs automatically after an install.

Morpheus API check (optional)

Confirms the API answers over the new certificate and whether the Appliance URL setting is covered by it. The token is kept in memory only.

5Runs and backups

Every install backs up /etc/morpheus/ssl and morpheus.rb first. Rolling back restores them and runs reconfigure + nginx restart; the state it replaces is saved as its own backup.
